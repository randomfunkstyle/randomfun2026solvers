# MNIST CNN Trainer on LM-1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An LM-1 machine that trains a small CNN on MNIST packed into its own grid, plotting train and validation loss and accuracy live on two LM-75 panels.

**Architecture:** MNIST is downsampled to 8x8 at 4 bits, nibble-packed five words to an image, and held in permanently-full recirculating ring FIFOs (one lap = one epoch, zero live men). Forward and backward passes are fully unrolled straight-line LM-1 assembly; the multiply-accumulate inner loops run inside an extended STREAM coprocessor at ~12 ticks each instead of ~650 on the CPU. Two LM-75 panels are each driven by their own relay room, because a room may feed at most one display.

**Tech Stack:** Python 3.12 stdlib only (no new dependencies), the repo's `lm1` package (assembler, emulator, `machine.build`, `stream.py`), the native `fast_littleman` engine for runs and the bundled wasm for probe grids.

**Design spec:** `docs/superpowers/specs/2026-07-29-mnist-cnn-design.md`. Read it before Task 1; every constant below traces to it.

## Global Constraints

- **No new dependencies.** `pyproject.toml` has `pydantic` and `networkx` only. Use `urllib.request`, `gzip`, `struct`, `array`. No numpy, no requests.
- **Python 3.12** (`requires-python = "==3.12.*"`), line length 100, ruff `select = ["E", "F", "I", "UP", "B"]`.
- **Fast test tier under ~10s, 30s hard maximum.** Default `pytest` runs `-m 'not slow'` with `-n auto`. Anything driving a real engine or a full training run is `@pytest.mark.slow`.
- **Tests assert correctness, never quality.** Do not assert a footprint, a tick count, a score, or an accuracy as a recorded value. Assert that tiers agree, that pipes bind, that a checked-in artifact matches its generator.
- **Tests never touch the network.** The MNIST fetch is a CLI subcommand only; tests read the vendored artifact.
- **Fixed point is Q12**, scale `4096`. `SCALE = 4096`, `SHIFT = 12`.
- **Dataset shape is fixed:** `IMG = 8` (8x8), `NIBBLE_BITS = 4`, `NIBBLES_PER_WORD = 15`, `WORDS_PER_IMAGE = 5`, `N_TRAIN = 2000`, `N_VAL = 1000`.
- **Fifteen nibbles a word, not sixteen.** Sixteen is 64 bits exactly; littleman values are *signed* 64-bit and ROM literals must additionally be non-negative (`rom.digit_width` raises on a negative word), so an all-white image would pack to `2^64 - 1` and be unrepresentable. Fifteen nibbles is 60 bits, max `1152921504606846975`, 19 digits. 64 pixels + 1 label = 65 nibbles fits in 5 words with 10 slots spare, so `WORDS_PER_IMAGE` is unchanged. **Every packed word must satisfy `0 <= w <= 2**63 - 1`.**
- **Model shape is fixed:** `N_FILTERS = 2`, `KERNEL = 3`, conv output 6x6x2, `MaxPool2` -> 3x3x2 = 18 features, `Dense(10)`, softmax, cross-entropy. No BatchNorm. Dropout defaults off.
- **Every generator writes its own sidecars** in one invocation: `--man` / `--html` / `--json` (`AGENTS.md`, `littleman/DEBUGGING.md`).
- **Colours:** background 0, axes 8, train series 9, validation series 14.
- **No optimisation work. The measured results are final.** Validation accuracy is 80-82%, an epoch is ~23 s on the emulator and ~5 min projected on the grid, and validation loss rises after epoch 8 because a fixed learning rate overfits 2,000 images. All of that is accepted as-is by decision of the user (2026-07-29): *"we can always optimize it in v2 if needed."* Do **not** change the model, the learning rate, the schedule, the data volume or the architecture to improve any of those numbers. Every tier's job from here is to reproduce the reference model faithfully, not to beat it. If you see an optimisation, put it in your report; do not implement it.

```python
from __future__ import annotations

import pytest

from randomfun2026solvers import mnist_data as md


def test_pack_round_trips_every_nibble_value():
    pixels = [i % 16 for i in range(64)]
    words = md.pack_image(pixels, label=7)
    assert len(words) == md.WORDS_PER_IMAGE
    assert all(w >= 0 for w in words), "ROM literals are digits only, so words must be non-negative"
    got_pixels, got_label = md.unpack_image(words)
    assert got_pixels == pixels
    assert got_label == 7


def test_every_packed_word_is_a_representable_rom_literal():
    """The reason a word holds fifteen nibbles and not sixteen.

    Sixteen nibbles is 64 bits, so an all-white image would pack to 2**64 - 1 —
    not a signed 64-bit value and not a non-negative ROM literal, and
    rom.digit_width raises on it. Fifteen nibbles is 60 bits.
    """
    words = md.pack_image([15] * 64, label=9)
    assert len(words) == 5
    for w in words:
        assert 0 <= w <= 2**63 - 1, f"{w} is not a representable ROM literal"
    assert md.unpack_image(words) == ([15] * 64, 9)


def test_packing_uses_fifteen_nibbles_per_word():
    """Pixel k lives in nibble k % 15 of word k // 15."""
    pixels = [0] * 64
    pixels[15] = 7  # first nibble of the second word
    words = md.pack_image(pixels, label=0)
    assert words[0] == 0
    assert words[1] == 7


def test_downsample_averages_three_by_three_blocks():
    """A uniform image stays uniform; 3x3 average pooling of a constant is that constant."""
    raw = bytes([255] * 784)
    pixels = md.downsample(raw)
    assert len(pixels) == 64
    assert set(pixels) == {15}, "255 >> 4 == 15"


def test_downsample_is_in_nibble_range():
    raw = bytes(range(256)) * 3 + bytes(16)
    pixels = md.downsample(raw)
    assert len(pixels) == 64
    assert all(0 <= p <= 15 for p in pixels)
```

- [ ] **Step 3: Write the implementation**

Create `mnist_data.py`. Key decisions, all forced by the spec:

- `downsample`: centre-crop 24x24 out of 28x28 (offset 2 on each axis), then average each 3x3 block, then `>> 4` to a nibble. Integer arithmetic only — `sum(block) // 9 >> 4`.
- `pack_image`: fifteen nibbles a word, little-end first. Pixel `p` lives in nibble `p % 15` of word `p // 15`: `words[p // 15] |= pixels[p] << (4 * (p % 15))`. That fills words 0-3 with fifteen pixels each and puts pixels 60-63 in nibbles 0-3 of word 4; **the label goes in nibble 4 of word 4**, the first spare slot. Assert `0 <= w <= 2**63 - 1` for every word before returning — the constraint is the reason for the fifteen.
- The artifact format: a 16-byte header (`b"LM1MNIST"`, then two `uint32` counts), then `train_words` and `val_words` as little-endian `uint64` via `struct`/`array`. Store the sha256 of the concatenated source idx files in a sidecar `.sha256` text file so `test_artifact_matches_recorded_hash` can pin it.
- `fetch_and_vendor` downloads these four files from `https://storage.googleapis.com/cvdf-datasets/mnist/`: `train-images-idx3-ubyte.gz`, `train-labels-idx1-ubyte.gz`, `t10k-images-idx3-ubyte.gz`, `t10k-labels-idx1-ubyte.gz`. Train subset = first 2000 of the train split; validation = first 1000 of the test split. Parse idx headers with `struct.unpack(">IIII", ...)`.
- `load_packed` reads the vendored artifact and raises a clear error naming the fetch command if it is absent.

### Task 2: The Q12 reference model

**Files:**
- Create: `solvers/python/randomfun2026solvers/mnist_model.py`

**Interfaces:**
- Consumes: `mnist_data.unpack_image`, `load_packed`, `WORDS_PER_IMAGE`
- Produces:
  - `SCALE = 4096`, `SHIFT = 12`
  - `class Params` with fields `conv_w: list[int]` (18, `[f*9 + t]`), `conv_b: list[int]` (2), `dense_w: list[int]` (180, `[j*18 + i]`), `dense_b: list[int]` (10)
  - `init_params(seed: int) -> Params` — deterministic LCG init, Q12
  - `forward(p: Params, pixels: list[int]) -> Forward` where `Forward` has `pre: list[int]` (72), `act: list[int]` (72), `pooled: list[int]` (18), `argmax: list[int]` (18), `logits: list[int]` (10), `probs: list[int]` (10, Q12, summing to ~4096)
  - `cross_entropy(probs: list[int], label: int) -> int` — Q12
  - `backward(p: Params, pixels: list[int], f: Forward, label: int) -> Grads` with the same shapes as `Params`
  - `sgd_step(p: Params, g: Grads, lr_shift: int) -> None` — in place, `w -= g >> lr_shift`
  - `exp_lut() -> list[int]` — 32 entries, Q12; plus a private 33-endpoint `_LN_MANT` log table used by `cross_entropy`
  - `train(params, epochs, lr_shift) -> list[EpochStat]` where `EpochStat` has `train_loss, train_acc, val_loss, val_acc` (all int, Q12 for loss, percent for acc)

```python
# tests/test_mnist_model.py
"""The Q12 fixed-point reference model — the oracle every other tier must match.

Design: docs/superpowers/specs/2026-07-29-mnist-cnn-design.md §4.

Pure integer arithmetic, so it is exact and cheap: the whole file belongs in the
fast tier. What is pinned is *behaviour* — that gradients agree with finite
differences, that softmax normalises, that shapes are what the hardware assumes —
never an accuracy, which is a quality number (AGENTS.md).
"""

from __future__ import annotations

from randomfun2026solvers import mnist_model as mm


def test_probs_sum_to_one_in_q12():
    p = mm.init_params(seed=1)
    pixels = [(i * 7) % 16 for i in range(64)]
    f = mm.forward(p, pixels)
    assert abs(sum(f.probs) - mm.SCALE) <= 10, "softmax must normalise to 1.0 in Q12"
    assert all(x >= 0 for x in f.probs)


def test_shapes_match_what_the_hardware_assumes():
    p = mm.init_params(seed=1)
    assert (len(p.conv_w), len(p.conv_b), len(p.dense_w), len(p.dense_b)) == (18, 2, 180, 10)
    f = mm.forward(p, [0] * 64)
    assert (len(f.pre), len(f.pooled), len(f.logits), len(f.probs)) == (72, 18, 10, 10)


def test_relu_zeroes_negative_preactivations():
    p = mm.init_params(seed=1)
    f = mm.forward(p, [(i * 3) % 16 for i in range(64)])
    assert all(a == max(0, q) for a, q in zip(f.act, f.pre, strict=True))


def test_dense_gradient_matches_finite_difference():
    """The gradient is the whole program; a sign error here is invisible downstream."""
    p = mm.init_params(seed=2)
    pixels = [(i * 5) % 16 for i in range(64)]
    label = 3
    f = mm.forward(p, pixels)
    g = mm.backward(p, pixels, f, label)

    eps = 64  # Q12: 64/4096 — big enough to beat truncation, small enough to be local
    for idx in (0, 37, 179):
        lo, hi = _loss_at(p, pixels, label, idx, -eps), _loss_at(p, pixels, label, idx, +eps)
        numeric = (hi - lo) * mm.SCALE // (2 * eps)
        assert _same_sign_and_magnitude(numeric, g.dense_w[idx])


def test_conv_gradient_matches_finite_difference():
    p = mm.init_params(seed=2)
    pixels = [(i * 5) % 16 for i in range(64)]
    label = 3
    f = mm.forward(p, pixels)
    g = mm.backward(p, pixels, f, label)
    eps = 64
    for idx in (0, 8, 17):
        lo = _loss_at(p, pixels, label, idx, -eps, which="conv_w")
        hi = _loss_at(p, pixels, label, idx, +eps, which="conv_w")
        numeric = (hi - lo) * mm.SCALE // (2 * eps)
        assert _same_sign_and_magnitude(numeric, g.conv_w[idx])


def _loss_at(p, pixels, label, idx, delta, which="dense_w"):
    import copy

    q = copy.deepcopy(p)
    getattr(q, which)[idx] += delta
    return mm.cross_entropy(mm.forward(q, pixels).probs, label)


def _same_sign_and_magnitude(numeric: int, analytic: int) -> bool:
    """Fixed point makes exact equality hopeless; agreement in sign and order is the claim."""
    if numeric == 0 or analytic == 0:
        return abs(numeric - analytic) <= mm.SCALE
    return numeric * analytic > 0 and 0.3 <= abs(numeric / analytic) <= 3.0
```

- [ ] **Step 3: Implement the model**

All arithmetic is `int`. Rules:

- A Q12 product is `(a * b) >> SHIFT`, using `>>` (floor), matching the engine's `}` and `DIVI 4096`.
- Pixels enter as `pixel * SCALE // 15` so the input is 0..1.0 in Q12.
- `init_params`: an LCG, `x = (x * 1103515245 + 12345) & 0x7FFFFFFF`, mapped to `+-SCALE//8` for conv and `+-SCALE//16` for dense. Deterministic in `seed`.
- Conv is valid 3x3 over 8x8 -> 6x6, per filter: `pre[f*36 + p] = conv_b[f] + sum_t (x[...] * conv_w[f*9 + t]) >> SHIFT`.
- `MaxPool2` over each 6x6 into 3x3, recording `argmax` as the index within `pre` so backward can route the gradient.
- Softmax: subtract `max(logits)`, index `exp_lut()` by **`(-z) >> 10`** clamped to entry 31, **linearly interpolating on the low bits below the clamp**, then normalise with integer division. Document the LUT's resolution in a comment — it is the one approximation in the forward pass.
  **This constant was originally specified as `>> 7` and that is wrong.** `>> 7` confines all 32 entries to `z` in (-1, 0]; logit gaps exceed 1.0 within one epoch, after which every trailing class shares one probability and the label's `dz` pins near -3169 forever. Measured: 30 configurations of `lr_shift` x init scale, none above 53%, against 80% for a double-precision exp. `>> 10` covers `z` in (-8, 0] — the whole range before Q12 exp underflows. Interpolation is what keeps the finite-difference tests non-vacuous; without it 95% of probes return an exact zero difference.
- Backward: `dz = probs - onehot(label)` (Q12), then dense grads, then `df`, then route through pool argmax, then ReLU mask, then conv grads. **No conv input gradient** — conv is the first layer.

**Interfaces:**

- Produces: four new command codes on `StreamUnit.CODES` — `PUSHA`, `ROTB`, `RDP`, `UPDB` — and their behaviour:
  - `PUSHA v` — `ring_a.append(v)`
  - `ROTB n` — pop `n` from `ring_b`, push each straight back (rotation, no product)
  - `RDP` — pop one value from `p1` and return it as the unit's response word
  - `UPDB n` — `n` times: `b = ring_b.popleft()`, `g = p1.popleft()`, `p2.append(g)`, `ring_b.append(b - ((a * g) >> lr_shift))` where `a` is the scalar most recently pushed by `PUSHA`

**Why this task is Python-only:** the grid is Task 6. Getting the *semantics* pinned first means Task 4 can write and debug the whole training program against a model, and Task 6 then has an oracle to match rather than a specification to interpret.

```python
# tests/test_mnist_stream_arms.py
"""The four STREAM arms the CNN needs and matmul did not.

Design: docs/superpowers/specs/2026-07-29-mnist-cnn-design.md §4.2a.

The existing eight arms fill rings from the *input room* and emit to the *output
room*; a training loop needs to push CPU-computed scalars in, rotate ring B to a tap
offset, read a partial sum back at the CPU, and update weights in place without
routing 190 words through the CPU. This file pins the semantics; the grid that
implements them is pinned in the same file's slow tier once it exists.
"""

from __future__ import annotations

from collections import deque

from randomfun2026solvers.lm1.store import StreamUnit


def _unit() -> StreamUnit:
    return StreamUnit(read_input=lambda: 0, emit=lambda v: None)


def test_new_arms_have_distinct_codes():
    codes = StreamUnit.CODES
    for arm in ("PUSHA", "ROTB", "RDP", "UPDB"):
        assert arm in codes, f"{arm} must be a STREAM arm"
    assert len(set(codes.values())) == len(codes), "two arms cannot share a command code"
    assert max(codes.values()) < 16, "a depth-4 trie has 16 leaves"


def test_pusha_puts_a_cpu_value_on_ring_a():
    u = _unit()
    u.command(8 * 42 + StreamUnit.CODES["PUSHA"])
    assert list(u.ring_a) == [42]


def test_rotb_rotates_without_consuming():
    u = _unit()
    u.ring_b = deque([1, 2, 3, 4, 5])
    u.command(8 * 2 + StreamUnit.CODES["ROTB"])
    assert list(u.ring_b) == [3, 4, 5, 1, 2], "a rotation preserves the multiset and the order"


def test_rotb_by_full_length_is_identity():
    u = _unit()
    u.ring_b = deque(range(7))
    u.command(8 * 7 + StreamUnit.CODES["ROTB"])
    assert list(u.ring_b) == list(range(7))


def test_rdp_returns_one_partial_sum_to_the_cpu():
    u = _unit()
    u.p1 = deque([111, 222])
    assert u.command(8 * 0 + StreamUnit.CODES["RDP"]) == 111
    assert list(u.p1) == [222]


def test_updb_applies_a_rank_one_update_in_place():
    """W[j] -= (a * g[j]) >> lr, with g rotating through the accumulator ring."""
    u = _unit()
    u.ring_b = deque([1000, 2000, 3000])
    u.p1 = deque([4096, 8192, 0])  # Q12 gradients 1.0, 2.0, 0.0
    u.lr_shift = 12
    u.command(8 * 3 + StreamUnit.CODES["PUSHA"])  # scalar a = 3
    u.command(8 * 3 + StreamUnit.CODES["UPDB"])
    assert list(u.ring_b) == [1000 - 3, 2000 - 6, 3000 - 0]
    assert list(u.p2) == [4096, 8192, 0], "the gradients must circulate, not be consumed"


def test_mac_still_does_what_matmul_relies_on():
    """A regression guard: the depth-4 trie must not renumber the existing arms' behaviour."""
    u = _unit()
    u.ring_a = deque([2])
    u.ring_b = deque([10, 20, 30])
    u.p1 = deque([0, 0, 0])
    u.command(8 * 3 + StreamUnit.CODES["MAC"])
    assert list(u.ring_b) == [10, 20, 30], "MAC rotates B back to its start after a full lap"
    assert u.macs == 3
```

`code_mask = (1 << trie_bits) - 1` and the decode is `arg, code = divmod(word, 1 << trie_bits)`.

At `trie_bits=3` the unit has the existing eight arms and `matmul`'s `8 * arg + code`
format, and must behave byte-identically to today. At `trie_bits=4` it additionally
has `PUSHA`, `ROTB`, `RDP` and `UPDB` at codes 8..11 with a `16 * arg + code` format;
constructing a `trie_bits=3` unit and issuing a code >= 8 must raise.

**Why not simply widen it:** the wire format is `arg * 2^bits + code`, so at 3 bits
`word % 8` is always 0..7 and codes 8..15 are unreachable — `PUSHA` with `arg=42`
encodes to 344, which decodes as `EMIT(43)`. At 4 bits every existing word with an odd
`arg` aliases: `FILLA` with `arg=35` is word 283, `(35, 3)` at mod-8 and `(17, 11)` at
mod-16, and `matmul`'s shipped cases exercise odd `arg`. There is no single decode that
serves both, and no residue-sniffing hybrid rescues it.

(there is none today — only `send`), and implement each arm exactly as the tests
