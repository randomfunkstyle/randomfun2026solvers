  • input the problem's own stream: `0 addr` (READ) / `1 addr value` (WRITE)
  • router / broadcaster `r` the op and branch on it. Each lane then reads the address and builds `1 << addr` with `M 1 {`, and `S` writes that into EVERY outgoing pipe at once. A READ then broadcasts 0; a WRITE broadcasts 1 and the value. This room owns no other outgoing pipe on purpose — `S` would broadcast into it too, which is why answers go through the collector instead.
