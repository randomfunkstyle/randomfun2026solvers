Output the n-th triangular number.

The input is a single integer n; output 1 + 2 + ⋯ + n. For n = 0 the sum is empty — output 0.

Format
Input. n — one integer.

input ⟶ n

e.g.
  0
  1
  4
Output. T — one integer.

output ⟶ T

e.g.
  0
  1
  10
Constraints
0 ≤ n ≤ 1000
